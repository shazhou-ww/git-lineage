# Support

## Usage help

Read the [README](./README.md) and command help first:

```sh
git-lineage --help
git-lineage <command> --help
```

Search existing
[GitHub Issues](https://github.com/shazhou-ww/git-lineage/issues) before opening
a new one. Use the bug report template for reproducible defects and the feature
request template for proposed behavior.

This community project does not provide a guaranteed response time or private
support service.

## Security

Do not use a public support request for vulnerabilities. Follow
[SECURITY.md](./SECURITY.md) to report them privately.
