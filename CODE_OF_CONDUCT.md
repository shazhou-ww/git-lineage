# Code of Conduct

## Our standards

We want participation in `git-lineage` to be welcoming, respectful, and
constructive. Examples of expected behavior include:

- discussing ideas and disagreements with empathy and technical focus;
- giving and accepting actionable feedback;
- respecting different backgrounds, identities, experiences, and skill levels;
- taking responsibility for mistakes and correcting them.

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, and sustained disruption are not acceptable in project spaces.

## Scope

This code applies to repository discussions, issues, pull requests, reviews, and
other spaces where someone represents the project.

## Enforcement

Project maintainers may edit or remove contributions and may temporarily or
permanently restrict participation when behavior is inappropriate, threatening,
offensive, or harmful.

Use GitHub's reporting controls to report abusive content privately to GitHub.
For project-specific moderation, open an issue containing no sensitive personal
information and request private follow-up from a maintainer. Do not use a public
issue to disclose a security vulnerability; follow [SECURITY.md](./SECURITY.md)
instead.

Maintainers will consider the context, protect reporter privacy as far as the
available tools allow, and respond proportionately and consistently.
