# Security Policy

## Supported versions

`git-lineage` is currently pre-1.0. Security fixes are provided for the latest
version published to npm. Upgrade to the current `latest` release before
reporting an issue that may already be fixed.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull
request.

Report it through
[GitHub private vulnerability reporting](https://github.com/shazhou-ww/git-lineage/security/advisories/new).
Include:

- the affected version and environment;
- reproduction steps or a minimal proof of concept;
- the expected and observed impact;
- any suggested mitigation, if known.

You should receive an initial acknowledgement within seven days. The maintainer
will validate the report, coordinate remediation and disclosure, and credit the
reporter when requested and appropriate. Please allow time for a fix to be
prepared and released before publishing details.

For ordinary bugs and usage questions, follow [SUPPORT.md](./SUPPORT.md).
